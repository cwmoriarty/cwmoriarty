### 🌳 Synology DSM Community Package Repository: `https://cpan.zip`

This repository hosts the official community packages for **[SynDirStat](syndirstat/)**, a free, open-source native Synology DSM 7 storage visualization and historical analysis application inspired by WinDirStat, WizTree, SequoiaView, and SpaceSniffer.

#### How to Add to Synology DSM Package Center:
1. Open your Synology DSM web desktop (DSM 7.x or 6.x).
2. Open **Package Center**.
3. Click **Settings** (top right) ➔ **Package Sources** ➔ **Add**.
4. Set:
   - **Name**: `cpan.zip`
   - **Location**: `https://cpan.zip`
5. Click **OK**. Navigate to the **Community** tab and click **Install** on **SynDirStat**.

#### Packages Available:
- **x86_64** (Intel & AMD 64-bit): [`packages/syndirstat/syn-dirstat-x86_64-1.0.0.spk`](packages/syndirstat/syn-dirstat-x86_64-1.0.0.spk)
- **ARM64** (Realtek & ARM 64-bit): [`packages/syndirstat/syn-dirstat-arm64-1.0.0.spk`](packages/syndirstat/syn-dirstat-arm64-1.0.0.spk)
- **Universal** (All DSM 7 models): [`packages/syndirstat/syn-dirstat-all-1.0.0.spk`](packages/syndirstat/syn-dirstat-all-1.0.0.spk)
